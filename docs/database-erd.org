* Schema Details

** waves
Primary table for Wave instances
- =id=: Primary key
- =wave_id=: Unique Wave identifier (e.g., "localhost!w+abc123")
- =creator=: Email of wave creator
- =created_at=: Creation timestamp

** wavelets
Wavelets are conversation threads within a Wave
- =id=: Primary key
- =wave_id=: Foreign key to waves table
- =wavelet_id=: Unique wavelet identifier (e.g., "localhost!conv+root")
- =creator=: Email of wavelet creator
- =creation_time=: Creation timestamp
- =version=: Current version number
- =history_hash=: Hash for version verification
- =last_modified_time=: Last modification timestamp
- =participants=: JSON array of participant emails
- =docs=: JSON object containing documents (main, digest, etc.)

** wavelet_updates
Tracks all updates/operations on wavelets
- =id=: Primary key
- =wave_id=: Foreign key to waves table
- =wavelet_id=: Foreign key reference
- =channel_id=: WebSocket channel number
- =update_data=: JSON containing the operation details
- =timestamp=: When the update occurred

* Document Structure

The =docs= JSON field in wavelets contains:

#+begin_src json
{
  "main": {
    "docId": "main",
    "contributors": ["user@domain"],
    "content": [
      "Text content",
      {"type": "line"},
      {"type": "element", "attributes": {...}}
    ]
  },
  "digest": {
    "docId": "digest",
    "contributors": ["user@domain"],
    "content": ["Summary text"]
  }
}
#+end_src

* Operations

Updates in =wavelet_updates.update_data= follow the Wave protocol:

#+begin_src json
{
  "type": "ProtocolWaveletUpdate",
  "operations": [
    {
      "type": "documentOp",
      "docId": "main",
      "components": [
        {"type": "retain", "count": 10},
        {"type": "characters", "text": "new text"},
        {"type": "deleteCharacters", "count": 5}
      ]
    }
  ]
}
#+end_src
